How to update this file
  1. Check off items or add new ones using the + row at the bottom of each section.
  2. Click ⬇ Save file — downloads an updated todo.html to ~/Downloads.
  3. Replace this file with the download:
    cp ~/Downloads/todo.html ~/strollopia_git_hub/todo.html
  4. Commit and push:
    cd ~/strollopia_git_hub && git add todo.html && git commit -m "update todo" && git push

To add a built-in seed item (stored in the file as code, not state): edit the REPOS array in the <script> block and commit the file directly — no need to use Save file for that.
